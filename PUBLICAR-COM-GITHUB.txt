RONDA EDITORIAL v2.4.3 — ATUALIZAÇÃO PELO GITHUB
=================================================

Esta versão corrige a interrupção após 30–45 segundos usando Cloudflare Queues.
O computador não precisa permanecer ligado e não é necessário instalar Node.js.

ETAPA 1 — CRIAR A FILA UMA ÚNICA VEZ
------------------------------------

1. No Cloudflare, abra Storage & Databases > Queues.
2. Clique em Create queue.
3. Use exatamente este nome:

   ronda-editorial-intelligent-jobs

4. Confirme a criação.

ETAPA 2 — ATUALIZAR O REPOSITÓRIO
---------------------------------

5. Extraia este ZIP.
6. No GitHub, abra Johny1313/ronda-editorial-webapp.
7. Substitua os arquivos e pastas atuais pelo conteúdo desta versão.
8. O arquivo package-lock.json deve permanecer ausente.
9. Confirme o commit diretamente na branch main.

ETAPA 3 — CONFIGURAÇÃO DO BUILD
-------------------------------

No Worker > Settings > Build, mantenha:

   Build command: npm run build
   Deploy command: npx wrangler deploy
   Version command: npx wrangler versions upload
   Root directory: /

O commit na main inicia o build automaticamente.

ETAPA 4 — O QUE O WRANGLER CONFIGURA
------------------------------------

O wrangler.jsonc contém:

- Worker: ronda-editorial-webapp
- D1 no binding DB
- Workers AI no binding AI
- Produtor da fila no binding INTELLIGENT_JOBS_QUEUE
- Consumidor da fila ronda-editorial-intelligent-jobs
- Uma tarefa por lote, início em até um segundo e até três tentativas
- Ronda automática a cada cinco minutos
- Observabilidade ativada

ETAPA 5 — VALIDAR
-----------------

Abra:

https://ronda-editorial-webapp.johnymoraes13.workers.dev/api/health

Confirme:

   "version": "2.4.3"
   "queueReady": true
   "executionMode": "cloudflare-queue"

Depois atualize a página com Ctrl + F5 e faça uma nova leitura inteligente.

Não é necessário executar novamente o schema.sql se a tabela intelligent_jobs
já existe. As tarefas antigas com status failed podem permanecer no banco; elas
não impedem novas leituras.
