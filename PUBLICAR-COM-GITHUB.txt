RONDA EDITORIAL v2.7.0 — PUBLICAÇÃO PELO GITHUB
================================================

OBJETIVO
--------
Publicar a Ronda com perfis editoriais, exemplos de escrita e carrosséis flexíveis em uma branch de preview antes de promover para produção. O YouTube continua em fila própria.

1. SUBSTITUIR O PROJETO
-----------------------
Substitua o conteúdo antigo pelo conteúdo completo deste pacote. Preserve:

  .github/workflows/ci.yml
  package-lock.json
  migrations/0004_youtube_integration.sql
  migrations/0005_d1_storage_guard.sql
  migrations/0006_user_profiles_and_flexible_carousels.sql
  src/youtube.js
  src/profile.js

Remova a pasta antiga dist e arquivos ALTERACOES-v*.txt. O histórico está em
CHANGELOG.md.

2. CRIAR UMA BRANCH DE TESTE
----------------------------
Crie uma branch, por exemplo:

  perfil-v2.7.0

Envie o pacote completo para essa branch. Evite Upload files em main.

3. CONFIGURAR WORKERS BUILDS
----------------------------
Cloudflare > Worker > Settings > Builds:

  Production branch: main
  Build command: npm ci && npm run check
  Deploy command: npx --yes wrangler@4.113.0 deploy
  Non-production deploy command:
    npx --yes wrangler@4.113.0 versions upload
  Root directory: /

4. RECURSOS DECLARADOS
----------------------
O wrangler.jsonc declara:

  DB                         banco D1
  AI                         Workers AI
  ASSETS                     interface estática
  INTELLIGENT_JOBS_QUEUE     leitura inteligente
  ROUND_JOBS_QUEUE           rondas de portais
  YOUTUBE_JOBS_QUEUE         coleta independente do YouTube

Filas:

  ronda-editorial-intelligent-jobs
  ronda-editorial-intelligent-jobs-dlq
  ronda-editorial-round-jobs
  ronda-editorial-round-jobs-dlq
  ronda-editorial-youtube-jobs
  ronda-editorial-youtube-jobs-dlq

5. CONFIGURAR A CHAVE DO YOUTUBE
--------------------------------
A chave nunca deve ser enviada ao GitHub.

Pelo terminal, na pasta do projeto:

  npx --yes wrangler@4.113.0 secret put YOUTUBE_API_KEY

Ou no painel:

  Worker > Settings > Variables and Secrets > Add
  Type: Secret
  Name: YOUTUBE_API_KEY
  Value: sua chave da YouTube Data API v3

6. APLICAR MIGRAÇÕES
--------------------
Após o deploy, execute uma vez:

  npx --yes wrangler@4.113.0 d1 migrations apply DB --remote

As migrações mais recentes são:

  0005_d1_storage_guard.sql
  0006_user_profiles_and_flexible_carousels.sql

A migração 0006 cria usuários, sessões, exemplos de escrita e guias de estilo.

7. VALIDAR O PREVIEW
--------------------
Abra:

  /api/self-test
  /api/health
  /api/status
  /api/youtube/status
  /api/youtube/latest

Confirme:

  version: 2.7.0
  youtube.configured: true
  youtube.queueReady: true
  catalogPortals: 39

Na interface:

1. Abra a aba YouTube.
2. Confirme que não existe gráfico.
3. Clique em Atualizar YouTube.
4. Aguarde o estado passar por Na fila, Coletando e Atualizado.
5. Valide cards de assuntos, vídeos, canais, alertas e termos.
6. Abra um link no YouTube para confirmar a apuração.
7. Execute uma Ronda de portais e confirme que ela continua independente.

8. PROMOVER
-----------
Depois do preview, abra Pull Request da branch perfil-v2.7.0 para main.
O merge executará o deploy de produção.

9. MONITORAR
------------
No Cloudflare, confira:

  Queues > ronda-editorial-youtube-jobs
  Worker > Observability
  D1 > youtube_collections
  D1 > youtube_term_results
  D1 > youtube_state

A coleta de vídeos em alta ocorre a cada 15 minutos. Um termo ativo é consultado
por rotação a cada 30 minutos quando há margem de cota. Erros de chave, quota ou
API afetam somente a aba YouTube.


Após o deploy da v2.7.0, aplique as migrações pendentes:

npx --yes wrangler@4.113.0 d1 migrations apply DB --remote

O Wrangler aplicará 0005 e 0006 quando ainda estiverem pendentes. A 0006 cria os perfis editoriais e as preferências de slides.


10. VALIDAR PERFIL E SLIDES FLEXÍVEIS
-------------------------------------
1. Abra a aba Perfil e crie uma conta com e-mail e senha.
2. Adicione um texto de pelo menos 40 caracteres.
3. Clique em Atualizar estilo.
4. Escolha o padrão de slides entre 3 e 15.
5. Abra um assunto da Ronda e selecione uma quantidade diferente.
6. Confirme que o servidor devolve exatamente a quantidade escolhida.
7. Saia e entre novamente para validar a sessão.

A versão 2.7.0 não exige novo binding no Cloudflare. Os perfis usam o mesmo D1.
Não há confirmação de e-mail nem recuperação automática de senha nesta versão.
