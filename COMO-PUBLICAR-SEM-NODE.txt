RONDA EDITORIAL v2.1.1 — PUBLICAÇÃO SEM NODE NO COMPUTADOR
==========================================================

Use GitHub + Cloudflare Workers Builds. Esse fluxo não exige Node.js instalado
no computador e configura corretamente o consumidor da Cloudflare Queue.

1. Crie a Queue ronda-editorial-intelligent-jobs no painel Cloudflare.
2. Extraia o ZIP e envie todos os arquivos ao repositório GitHub.
3. Mantenha o Worker conectado à branch main.
4. Build command: npm run build
5. Deploy command: npx wrangler deploy
6. Aguarde o build verde.
7. Valide /api/health e confirme queueReady:true.

Não use apenas o botão Edit code para esta versão. Colar somente o bundle pode
publicar o código, mas não é o fluxo recomendado para configurar automaticamente
o produtor e o consumidor da Queue definidos no wrangler.jsonc.
